# InnovationAMP · Оценка на обученията

Анонимна онлайн форма за оценка на обученията, проведени от Институт GATE по проекта InnovationAMP, с админ панел за резултатите.

- **`index.html`** — формата за участниците
- **`admin.html`** — админ панел: статистика, графики, коментари, експорт, триене
- **`backend/Code.gs`** — бекенд (Google Apps Script), базата данни е Google таблица

Фронтендът е статичен и работи на GitHub Pages. Докато бекендът не е свързан, сайтът е в **демо режим**: отговорите се пазят само в браузъра, а админ паролата е `demo`.

## Как работи формата

1. Участникът отбелязва в кои обучения е участвал (едно или повече).
2. За всяко избрано обучение се отваря отделен раздел (таб) с 5 въпроса по скала 1–5 и поле за коментар (до 1024 знака, по желание).
3. Има един общ бутон **„Изпрати оценката“**. Ако някъде липсва оценка, формата не се изпраща, а връща участника към първото недовършено обучение и маркира пропуснатите въпроси.

Не се събират имена, имейли, IP адреси или други лични данни. Сървърът проверява повторно, че отговорът е пълен.

## Пускане на бекенда (еднократно, ~5 минути)

1. Влезте в Google акаунта, в който да стоят данните, и създайте нова **Google таблица** (напр. „InnovationAMP – оценки“).
2. В таблицата: **Extensions → Apps Script**.
3. Изтрийте съдържанието на `Code.gs` и поставете цялото съдържание на [`backend/Code.gs`](backend/Code.gs).
4. **Сменете паролата** на реда `const ADMIN_PASSWORD = 'СМЕНИ-МЕ';` с Ваша. Правете го само в редактора на Apps Script — не в GitHub, защото хранилището е публично. Докато паролата не е сменена, админ панелът отказва достъп.
5. Запазете (Ctrl+S), изберете функцията `setup` от падащото меню и натиснете **Run**. Разрешете достъпа, когато Google попита. Това създава листа „Отговори“.
6. **Deploy → New deployment** → тип **Web app**:
   - Execute as: **Me**
   - Who has access: **Anyone**
7. Копирайте адреса, завършващ на `/exec`.
8. Поставете го в [`assets/js/config.js`](assets/js/config.js) на мястото на `PASTE_APPS_SCRIPT_URL_HERE`, запазете и качете промяната в GitHub.

> При всяка следваща промяна в `Code.gs`: **Deploy → Manage deployments → Edit (молив) → Version: New version → Deploy**. Иначе продължава да работи старата версия.

## Публикуване в GitHub Pages

1. GitHub Desktop → **File → Add local repository** → изберете тази папка → **Publish repository** (махнете отметката „Keep this code private“).
2. В GitHub: **Settings → Pages → Deploy from a branch → `main` / `(root)`**.
3. Формата е на `https://<потребител>.github.io/<хранилище>/`, админ панелът — на `.../admin.html`.

## Админ панел

- Филтър по обучение; брой участници, средна оценка, дял на положителните отговори.
- Средна оценка по въпроси и разпределение на оценките 1–5 за всяко обучение.
- Списък с коментарите и таблица с всички отговори.
- **Кошче** на всеки ред — изтрива само оценката за това обучение.
- **„Изтрий цялата база“** — изисква да напишете `ИЗТРИЙ`; изтрива всички редове.
- **„Експорт в CSV“** — отваря се директно в Excel.

Данните могат да се гледат и обработват и направо в Google таблицата.

## Настройки

| Какво | Къде |
|---|---|
| Адрес на бекенда | `API_URL` в `assets/js/config.js` |
| Затваряне на анкетата | `FORM_OPEN: false` в `config.js` **и** `FORM_OPEN = false` в `Code.gs` |
| Задължителен коментар | `COMMENT_REQUIRED: true` в `config.js` |
| Обучения и въпроси | `TRAININGS` / `QUESTIONS` в `config.js`; ключовете на обученията трябва да съвпадат с `TRAININGS` в `Code.gs` |
| Админ парола | `ADMIN_PASSWORD` в `Code.gs` (в Apps Script) |

## Локално пускане

```bash
python -m http.server 8318
```

После отворете `http://localhost:8318`.
